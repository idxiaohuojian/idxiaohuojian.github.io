📖 使用指南速览

为什么需要一个外区 Apple ID

小火箭（Shadowrocket）只在 App Store 上架，且不对中国大陆区提供——国内区商店里搜不到。想下载它，必须用一个非中国大陆区的 Apple ID 登录 App Store。

最重要的一条：只在 App Store 登录

共享账号绝对不要在「设置 → 顶部头像」处登录 iCloud。那是 iCloud 入口，账号一旦登录进去，设备会与对方账号绑定，存在被远程锁定与数据泄露的风险。

下载完成后请及时退出

下载完直接关掉 App Store，账号会一直保持登录，既占用账号也可能因同时在线设备过多触发 Apple 风控导致锁定。请回到 App Store 账户页滑到底部退出共享账号。

共享账号和独享账号怎么选

共享账号是多人共用同一个 Apple ID 登录 App Store 下载，便宜但有被锁风险；独享账号是专属你一个人的账号，价格更高但更稳定，适合长期使用。

❓ 常见问题

Shadowrocket 为什么 App Store 里搜不到？

Shadowrocket 主要在美区上架。若你当前的 Apple ID 地区不在美区，通常搜不到或提示「在你所在国家或地区不可用」，需要改用美区 Apple ID 登录后购买/下载。

小火箭共享账号和独享账号有什么区别？

共享账号是多人共用同一个 Apple ID 登录 App Store 下载，便宜但有被锁风险；独享账号是专属你一个人的账号，价格更高但更稳定，适合长期使用。

第一次打开 Shadowrocket 要注意什么？

首次打开需授予 VPN 配置权限，之后添加节点（服务器地址、端口、密码、加密方式），点击节点开关连接，状态栏出现 VPN 图标即成功。
