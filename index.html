🔗 小火箭添加订阅链接教程

详细版 →
  1. 复制订阅地址：在服务商的用户中心找到「订阅链接」，整条复制。注意别只复制了前半段——长链接被聊天软件截断是最常见的导入失败原因。
  2. 小火箭里新建订阅：打开 Shadowrocket，底部切到「首页」，点右上角 +，类型选 Subscribe，把地址粘进 URL 栏，备注写个能认出的名字，点「完成」。
  3. 更新订阅拉取节点：点订阅右侧的「i」或左滑，选「更新」。拉取成功后分组下面会展开一串节点；没展开说明还没拉。
  4. 选节点连上验证：点一个节点，回首页打开顶部开关，首次会弹 VPN 配置授权。连上后打开浏览器实测一个网站，别只看开关亮没亮。
⚠️
更新失败先查这三点：地址是否完整复制、复制到的是不是管理页面而不是订阅本身、设备时间是否准确（时间偏差大会导致 HTTPS 证书校验失败）。三条都对还是不行，再用浏览器直接打开订阅地址看返回什么。

  2. 在 App Store 退出当前账号：打开 Mac 上的 App Store，点右上角头像，滑到底部选「退出登录」。目的是换成能下载 Shadowrocket 的美区账号。
  3. 登录已购账号：用自己买过小火箭的美区 ID，或共享账号登录。若弹「保护账户升级」，点「其他选项」→「不升级」，共享账号通常过不了验证流程。

📖 使用指南速览

为什么需要一个外区 Apple ID

小火箭（Shadowrocket）只在 App Store 上架，且不对中国大陆区提供——国内区商店里搜不到。想下载它，必须用一个非中国大陆区的 Apple ID 登录 App Store。

最重要的一条：只在 App Store 登录

共享账号绝对不要在「设置 → 顶部头像」处登录 iCloud。那是 iCloud 入口，账号一旦登录进去，设备会与对方账号绑定，存在被远程锁定与数据泄露的风险。

下载完成后请及时退出

下载完直接关掉 App Store，账号会一直保持登录，既占用账号也可能因同时在线设备过多触发 Apple 风控导致锁定。请回到 App Store 账户页滑到底部退出共享账号。

共享账号和独享账号怎么选

共享账号是多人共用同一个 Apple ID 登录 App Store 下载，便宜但有被锁风险；独享账号是专属你一个人的账号，价格更高但更稳定，适合长期使用。

❓ 常见问题

Shadowrocket 为什么 App Store 里搜不到？

Shadowrocket 主要在美区上架。若你当前的 Apple ID 地区不在美区，通常搜不到或提示「在你所在国家或地区不可用」，需要改用美区 Apple ID 登录后购买/下载。

小火箭共享账号和独享账号有什么区别？

共享账号是多人共用同一个 Apple ID 登录 App Store 下载，便宜但有被锁风险；独享账号是专属你一个人的账号，价格更高但更稳定，适合长期使用。

第一次打开 Shadowrocket 要注意什么？

首次打开需授予 VPN 配置权限，之后添加节点（服务器地址、端口、密码、加密方式），点击节点开关连接，状态栏出现 VPN 图标即成功。
